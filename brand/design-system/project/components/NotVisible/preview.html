Not visible to the console

These also decide what an agent may do, but the console cannot read them. Look in ncl or on the agent host.

  • Per-group environment variables

    ncl leaves env out of a group’s config, and the console never reads NanoClaw’s database or .env.

  • OneCLI secret assignments

    They live in OneCLI’s vault; the console has no access to OneCLI.

  • Egress lockdown

    It is an environment setting of NanoClaw’s and a Docker network; the broker has neither the Docker socket nor .env.
